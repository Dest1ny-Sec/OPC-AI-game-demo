# 《弄堂沉浮录·1936》剧情 v7 完整打磨版

> **重要说明**：v6 是增量，**v7 是重做**。v5 的 4 卷框架 + 28 节点保留，**所有代码（asylum/failures/branching/metaAI/npcAgents/store/story）都不动**，v7 是**给 v5 补玩法、补机制、补时间线**。
> **核心新增**（基于用户反馈）：
> 1. **穿越者张力机制**（不能被发现 + NPC 怀疑度）
> 2. **传话/牵线/挖礼物** 三大核心玩法
> 3. **商城/背包系统**
> 4. **地下党/抗联 NPC 升级**（"解放军"是用户口语，1936 年应叫"地下党"或"抗联"）
> 5. **最后 10 天"山雨欲来 + 清明 + 梦回 1937"**（严谨时间线）
> 6. **坏结局系统整合**（asylum + 4 种失败路径 + 6 分支结局）
>
> **原则**：每个机制都对应**至少一个 v5/v6 的固定点**，**不做加法**，**只补缺**

## Part 1：穿越者张力机制（这是游戏的"地基"）

### 1.1 现状问题

v5/v6 都设定了"1936 年魂穿"但**没有任何机制让"不能被发现"成为真实约束**。metaAI.js 只有"瞎玩检测"（OOC > 50%），但**没有"NPC 怀疑玩家是未来人"的双轨张力**。

**用户的核心痛点**："穿越，然后不能被人发现是穿越否则被抓入精神病院"

**解法**：加一个 **NPC 怀疑度** 字段，每个 NPC 独立追踪。

### 1.2 怀疑度机制设计

#### 1.2.1 字段定义（追加到 `store.js` 的 initialGameState）

```js
suspicion: {
  xiangsongmao: 0,  // 0-100，越高越怀疑
  fangyexian: 0,
  guole: 0,
  bajin: 0,
  wangpo: 0,
  xunpu: 0,         // 巡捕阿德，怀疑度增长最快
  qingbang: 0,
  rishang: 0,
  dixia: 0,         // 地下党
}
```

#### 1.2.2 怀疑度增长触发器（4 类）

| 触发器 | 怀疑度增长 | 备注 |
|---|---|---|
| **说错时代细节**（"上海什么时候解放的？"） | +15 | 玩家最容易犯的错 |
| **说现代词**（"手机""网络""App""玩家""boss""剧情"） | +10 | LLM 检测 |
| **预言准确**（"1937 年会打仗"——但被验证） | +25 | 最危险——一次说对 +25 |
| **预言错误**（"1937 年不会打仗"） | +5 | 玩家想隐藏未来记忆但说错 |
| **行为诡异**（半夜不睡觉、盯着收音机听广播） | +3/次 | 慢速累积 |
| **与抗日/共产党相关过密** | +5/次 | 巡捕阿德专属触发 |
| **跟王婆讲"未来"的事** | +20 | 王婆嘴碎，会传出去 |

#### 1.2.3 怀疑度降低触发器（3 类）

| 触发器 | 怀疑度降低 | 备注 |
|---|---|---|
| **说地道沪语**（"侬""阿拉""晓得""作数"） | -2/次 | 装得像本地人 |
| **送 NPC 喜欢的礼物**（挖出来的） | -10 | 贿赂/讨好 |
| **帮忙 NPC 完成私事**（挖出来的） | -15 | 信任建立 |
| **主动讲"我做了个奇怪的梦"** | -5 | 把"预言"包装成"梦"——但只能偶尔用 |
| **说错时代细节 + 自我打圆场**（"阿拉听人讲……侬晓得伐……"） | -5 | 自圆其说能力 |

#### 1.2.4 怀疑度的 NPC 差异

| NPC | 怀疑度增长 | 怀疑度降低 | 特殊规则 |
|---|---|---|---|
| **项松茂** | 慢（+5 触发） | 中（-10 礼物） | 护短——你帮他，他就不追问 |
| **方液仙** | 慢（+5） | 中（-10） | 圆滑——你圆滑，他装没听到 |
| **郭乐** | 中（+8） | 慢（-5） | 精明——他**不会直接怀疑**，但会**派人去查你** |
| **巴金** | **最慢**（+3） | 快（-15） | 温和——他**帮你圆场**："账房先生昨天喝多了……" |
| **王婆** | 快（+12） | 快（-15） | 嘴碎——你跟她讲，她**明天全武康路都知道了** |
| **巡捕阿德** | **最快**（+20） | 慢（-5） | **最危险**——他可以直接抓你进精神病院 |
| **青帮马仔** | 中（+10） | 中（-10） | 只看利益——你交保护费，他不追问 |
| **日商买办** | 中（+8） | 中（-10） | 装糊涂——他**不关心你从哪来**，只关心你卖不卖日货 |
| **地下党** | **最慢**（+2） | **最快**（-20） | 同路人——他**帮你隐藏**，但有条件（你要帮他们） |

#### 1.2.5 怀疑度阈值

| 阈值 | 后果 |
|---|---|
| **0-30** | 正常，NPC 信任你 |
| **31-50** | NPC 偶尔用奇怪眼神看你 |
| **51-70** | NPC 主动跟别人聊你，**开始传播**（王婆特别快） |
| **71-85** | NPC **直接质问**你："侬到底从哪来？" |
| **86-100** | 触发**精神病院结局**（v5 已有：被法租界巡捕房送入虹口疯人院） |

**触发精神病院的特殊规则**：
- **巡捕阿德** 怀疑度 > 70 → **直接抓**（不需要 86）
- **王婆** 怀疑度 > 50 且**已经传出去 3 个人** → **间接触发**（王婆跟你邻居讲，邻居跟巡捕讲）
- **4 核心 NPC** 中 **3 个** 怀疑度 > 70 → **集体怀疑**，联合举报

#### 1.2.6 怀疑度 ≠ 不信任 ≠ 不给任务

**关键设计**：怀疑度高的 NPC **仍然可以跟玩家做交易**，但**不再透露个人故事**，**不再邀请进屋**。

例：
- 玩家怀疑度 60，跟项松茂做买卖 → 项松茂卖货但不再请玩家进书房
- 玩家怀疑度 80 → 项松茂只卖货，其他一律不答

**这样玩家不会因为"担心怀疑度高"就不敢做交易**——怀疑度高 ≠ 不能玩，只是**关掉支线**。

### 1.3 穿越者"安全话题"白名单（给 LLM 教学用）

LLM 必须知道**1936 年的玩家可以聊什么**（不会增加怀疑度）和**不能聊什么**（会增加）。

#### 1.3.1 安全话题（不会 + 怀疑度）
- 1936 年的物价、新闻、武康路、弄堂
- NPC 已知的历史（如项松茂 1912 推 131 牙膏——**这是 NPC 自己知道的**）
- 沪语、上海话
- 当天的天气、弄堂八卦、王婆的茶
- 4 核心 NPC 的**已公开作品**（巴金的《家》——**但 1936 年《家》1931 年已出版，所以可以聊**）
- 普通家常

#### 1.3.2 危险话题（+5 怀疑度/次）
- **未来事件**（1937/1949/1953/1956/2026）
- **未来人物**（新中国领导人、未来作家）
- **未来地名**（南京/北京作为首都——1936 年是北平！）
- **现代概念**（手机/网络/App/电脑/电视）
- **未公开的历史细节**（NPC 不知道的家族秘密）

#### 1.3.3 灰色话题（+2 怀疑度/次，玩家可以试但要小心）
- 把"预言"包装成"梦"（"阿拉昨夜做了个怪梦，梦见上海打仗"）
- 把"未来词"包装成"弄堂俚语"（"阿拉听个老克勒讲过……"）
- 把"未公开历史"包装成"听说"（"阿拉听讲，项老板您以前……"）

### 1.4 怀疑度 + 好感度 = 双轨关系模型

v5 的 `relations` 字段是单轴的"好感度"。v7 升级为**双轴**：

| | 好感度低 | 好感度高 |
|---|---|---|
| **怀疑度低** | 冷淡（正常） | 信任（核心支线开放） |
| **怀疑度高** | 敌对（坏结局风险） | 矛盾（NPC 喜欢你但警惕你） |

**举例**：
- 玩家跟项松茂好感度 90 但怀疑度 60 → 项松茂仍请你吃饭，但**私下派人查你底细**
- 玩家跟巡捕阿德好感度 30 但怀疑度 50 → 危险——阿德随时会抓你
- 玩家跟巴金好感度 70 但怀疑度 30 → **理想状态**——巴金最信任你，最能帮你圆场

**关键洞察**：**巴金是"穿越者最佳盟友"**——他怀疑度增长最慢、降低最快、还会主动帮你圆场。**但巴金的代价是：他要你帮地下党**（v5 节点 6 "黎明的方向"已埋）

### 1.5 怀疑度的"防滥用"机制

**问题**：玩家可以**无脑送礼 + 帮 NPC 做事**来降低怀疑度——这就不是"穿越者张力"了。

**解法**：
1. **送礼有上限**——每天只能送 1 个礼物，NPC 不会天天收礼
2. **帮 NPC 做事**要**先解锁支线**（支线由好感度阈值开启）——**不是白送**
3. **怀疑度一旦 > 50**，单次操作降低幅度减半（怀疑已经种下，很难拔）
4. **预言准确的代价**——即使你后来圆回来了，**+25 怀疑度**已经发生，**不可撤销**

## Part 2：传话/牵线搭桥/挖礼物（核心玩法）

### 2.1 现状问题

v5/v6 完全没有"传话/牵线"机制。v6 我加的"NPC 私下通信"是**给 LLM 看的背景**，不是**给玩家玩的机制**。

**用户的核心需求**：
- "做传话、做牵线达桥"
- "完成 A 想跟 B 做生意"
- "赠送 NPC 喜欢的礼物增加好感（**这个要靠自己去挖掘**）"
- "好感度高后 NPC 会讲自己的故事，就像朋友聊天"

**4 个核心玩法，我合并为 1 个核心系统：传话牵线 + 挖礼物 = 真实社交模拟**。

### 2.2 传话系统设计（A→玩家→B）

#### 2.2.1 触发条件

**每个 NPC 都有 1-3 个"想跟另一个 NPC 做生意/和解/传话"的隐藏任务**：

| NPC | 想传话给 | 内容 | 触发条件（NPC 好感度） |
|---|---|---|---|
| **项松茂** | 方液仙 | "侬能不能帮阿拉问问，方老板的 131 牙膏配方卖不卖" | 项松茂好感度 ≥ 60 |
| **项松茂** | 郭乐 | "阿拉想让 131 牙膏进永安百货，侬帮阿拉探探郭老板口风" | 项松茂好感度 ≥ 75 |
| **方液仙** | 项松茂 | "侬帮阿拉跟项老板讲，三星牙膏跟 131 牙膏联手做国货" | 方液仙好感度 ≥ 70 |
| **方液仙** | 郭乐 | "阿拉想进永安百货专柜，侬帮阿拉问问" | 方液仙好感度 ≥ 65 |
| **郭乐** | 项松茂 | "永安百货想独家代理 131 牙膏上海南区分销" | 郭乐好感度 ≥ 60 |
| **郭乐** | 方液仙 | "永安百货想开国货专柜，请方老板来谈" | 郭乐好感度 ≥ 70 |
| **巴金** | **鲁迅** | "阿拉想把这月写的小说寄给豫才先生看，侬帮阿拉寄" | 巴金好感度 ≥ 80 |
| **巴金** | 王婆 | "王婆的丈夫（地下党）有遗物，侬帮阿拉问问还在不在" | 巴金好感度 ≥ 75 |
| **王婆** | 地下党林先生 | "王婆想给苏区寄一批药品，侬帮阿拉找林先生" | 王婆好感度 ≥ 70 |
| **青帮马仔** | 项松茂 | "张啸林想入股五洲大药房，侬帮阿拉探探项老板" | 青帮关系 ≥ 50 |
| **地下党林先生** | 王婆 | "林先生想找王婆，侬帮阿拉传个信" | 地下党关系 ≥ 60 |

#### 2.2.2 传话流程

```
玩家从 NPC A 接到传话任务
   ↓
玩家在 7 天内找到 NPC B
   ↓
玩家向 NPC B 转达（**可加料、可删减、可说谎**）
   ↓
NPC B 给出回应
   ↓
玩家回到 NPC A 汇报
   ↓
NPC A 好感度 +15，B 好感度 +10 或 -20（看玩家怎么传）
```

**关键：传话是"有失真率"的**——玩家可以选择：
- **原话传**（NPC A +15，B +10，但 B 知道是 A 派来的）
- **加点料**（"B 老板其实很尊重 A"）——**有 30% 概率被识破**（NPC B 觉得你在骗他）
- **删减**（不传 A 的某些话）——**安全**但 A 觉得你办事不力（+5）
- **说谎**（"B 拒绝了"——其实是 B 没拒绝）——**有 50% 概率被识破**，被识破两个 NPC 一起 -30

#### 2.2.3 传话的好结局

**完美传话**触发"NPC 关系网联动"——A 和 B 关系 +20，**玩家同时获得 A 和 B 的隐藏礼物**（v6 钉子回收提前）。

**示例**：玩家帮项松茂给方液仙传话"想合作" → 项松茂 +15，方液仙 +10 → **触发"方项联手"事件** → **钉五"方液仙德文配方本"提前解锁**（v6 第 92 天回收 → 第 65 天提前）

#### 2.2.4 传话的坏结局

**传话失败**触发"误会加深"——A 和 B 关系 -20，**玩家可能被两个 NPC 同时拒绝**。

**示例**：玩家帮项松茂给方液仙传话"想收购"（其实项松茂说的是"合作"） → 方液仙翻脸 → **项松茂也翻脸**（"侬怎么能瞎讲"）

#### 2.2.5 传话机制的"防作弊"

**玩家不能直接传话，必须有"见面证据"**——每个 NPC 都有"今天是否见过"的 flag：
- 玩家说"我今天见过方液仙"——必须有 flag，否则 NPC A 说"侬在骗阿拉"
- 这逼玩家**真正去跑腿**，不能瞎传

### 2.3 牵线搭桥系统（A+B 想合作，玩家做中间人）

#### 2.3.1 触发条件

**两个 NPC 都想跟对方合作，但都抹不开面子**——玩家做中间人。

**示例**（v5 链路 2 的强化）：
- 项松茂想进永安百货，但跟郭乐不熟
- 郭乐想开国货专柜，但不知道找谁
- **玩家牵线** → 双方见面 → 签合同

**关键触发**：
- 玩家 A 好感度 ≥ 60 且 B 好感度 ≥ 60
- 玩家**不能直接做**——必须分别接 A 的话和 B 的话
- 玩家**不能强拉**——双方都有"今天是否见过"的 flag

#### 2.3.2 牵线流程

```
玩家接到 A 的牵线请求（"阿拉想跟 B 合作，侬帮阿拉约"）
   ↓
玩家去找 B，转达 A 的意思
   ↓
B 给出回应："行/不行/再看看"
   ↓
玩家回 A 汇报
   ↓
如果 A 和 B 都同意 → 玩家安排"三方会谈"
   ↓
三方会谈成功 → A+B 关系 +30，**玩家获得"牵线达人"成就**
   ↓
A+B 合作成功 → **玩家获得双方隐藏礼物 + 时代碎片 ×2**
```

#### 2.3.3 牵线的"特殊规则"

**"独家代理"牵线**：
- 郭乐说"永安百货想独家代理 131 牙膏"
- 玩家牵线 → 项松茂同意 → **签独家代理合同** → **项松茂给玩家分红 10%**
- **这就是用户说的"通过 NPC 赚钱"**

**"竞争对手握手"牵线**：
- 项松茂和方液仙想联手做"国货联盟"
- 玩家牵线 → 双方见面 → 玩家**见证**这场历史性握手
- **v6 没写过这场握手——v7 加上**

### 2.4 挖礼物系统（核心差异化）

**用户原话**："赠送 NPC 喜欢的礼物增加好感（**这个要靠自己去挖掘**）"

**关键**：玩家**必须自己去发现** NPC 喜欢什么——**没有提示，没有 hint**。

#### 2.4.1 NPC 喜欢的礼物池（玩家不可见）

**这些是 v7 给 LLM 的 NPC 礼物池——玩家看到 NPC 喜欢一个东西，要靠"听其言观其行"**：

| NPC | 喜欢什么 | 玩家怎么发现 |
|---|---|---|
| **项松茂** | ① 任何国货（非日货） ② 写有"项氏""松茂"的字画 ③ 1932 年前的老照片 ④ 一杯龙井茶 | 项松茂看到日货翻脸（玩家就知道他爱国产） |
| **方液仙** | ① 任何化学相关的小玩意（德国试剂/英国 pH 试纸） ② 写有"化学""工业"的新书 ③ 一支好钢笔（他签合同用） ④ 一块怀表 | 方液仙在实验室里摆弄钢笔（玩家看到想买给他） |
| **郭乐** | ① 广东家乡的食物（荔枝干/广式月饼） ② 一块好砚台（他练字） ③ 一副老花镜（他眼花了） ④ 永安百货的旧股票 | 郭乐咳嗽时用广东话骂"鬼佬"（玩家知道他是广东人） |
| **巴金** | ① 任何新出的书 ② 写有"巴金""李尧棠"的剪报 ③ 一支好钢笔（他写作） ④ 一封鲁迅的回信（很难拿到） | 巴金在书房叹气"要是能跟豫才先生通封信就好了"（玩家知道要帮巴金寄信） |
| **王婆** | ① 任何好吃的（她贪吃） ② 丈夫张德顺的旧物（很稀有） ③ 一瓶好酒（夜里独酌） ④ 任何关于地下党的消息 | 王婆看到红木盒发呆（玩家知道里面有故事） |
| **巡捕阿德** | ① 任何广东食物（他家乡） ② 一杯威士忌（洋人的酒他爱喝） ③ 一份法租界的内部通知 ④ 一盒好香烟 | 阿德巡逻时哼粤曲（玩家知道他是广东人） |
| **青帮马仔** | ① 任何银元 ② 一把好刀 ③ 一壶好酒 ④ 一张青帮堂口的老照片 | 马仔腰间别着刀（玩家知道要送刀） |
| **日商买办** | ① 任何日本货（仁丹/万金油/相机） ② 一张日本明信片 ③ 一瓶清酒 ④ 一份日语报纸 | 买办桌上摆日本清酒（玩家知道） |
| **地下党林先生** | ① 任何药品（盘尼西林/阿司匹林） ② 一支好钢笔（他写密信） ③ 一本《资本论》 ④ 一张苏区的明信片（极稀有） | 林先生说"阿拉最缺西药"（玩家知道） |

#### 2.4.2 礼物的"档次"系统

| 档次 | 例子 | 效果 | 玩家怎么获得 |
|---|---|---|---|
| **普通礼物** | 一包大前门 / 一斤白糖 / 一双布鞋 | 好感度 +3 | 商城购买（Part 3） |
| **稀有礼物** | 一块怀表 / 一瓶好酒 / 一支好钢笔 | 好感度 +10 | 特殊途径（黑市/十六铺码头/王婆茶馆八卦） |
| **定制礼物** | 项松茂的字画 / 鲁迅的回信 / 1932 年的老照片 | 好感度 +25 | **只有玩家自己发现**才能获得 |
| **情感礼物** | 丈夫张德顺的遗物 / 苏区的明信片 | 好感度 +40 | **极稀有**——通过传话/支线获得 |

#### 2.4.3 挖礼物的"无提示"机制

**关键设计**：游戏**绝不告诉玩家** "项松茂喜欢 A，B，C"。

**玩家发现 NPC 喜好的 4 种途径**：
1. **听其言**——NPC 偶尔提到"阿拉最近想要 X"
2. **观其行**——NPC 房间里摆着某物（玩家进 NPC 房间才能看到）
3. **问旁人**——王婆的茶馆是情报中转，玩家问"项老板喜欢啥"会得到八卦线索
4. **试错**——玩家送礼，NPC 接受（+好感度）= 玩家记住"他喜欢这个"；NPC 拒绝（不增加）= 玩家知道"他不喜欢这个"

**试错机制的好处**：
- 玩家会**主动探索** NPC 房间（增加沉浸感）
- 玩家会**主动跟王婆聊天**（情报中转有意义）
- 玩家**记笔记**（自己画小本本）

**试错机制的代价**：
- 玩家送错礼物**不会扣好感度**（避免挫败感）
- 但**消耗物品**（背包里东西少了）

#### 2.4.4 礼物与怀疑度的互动

**关键规则**：
- 玩家给 NPC 送礼 → **好感度 +3-40**（看档次）
- **如果 NPC 怀疑度高 (>50)** → 送礼效果**减半**（"侬这是想堵阿拉的嘴？"）
- **如果 NPC 怀疑度低 (<30)** → 送礼效果**加倍**（"侬真有心，阿拉收下了"）
- **如果 NPC 怀疑度极高 (>70)** → 送礼**无效**（"侬走开"）

**这给玩家"补救机会"**——怀疑度高时**少说多做**（多送礼少说话）可以降低怀疑度。

### 2.5 "朋友聊天"机制（好感度 ≥ 70 触发）

**用户原话**："好感度高后，NPC 也会讲一些自己的故事，就像朋友聊天"

**v5 节点设计已经埋了**——但**没明确触发条件**。v7 明确：

#### 2.5.1 触发条件
- NPC 好感度 ≥ 70
- **且**玩家**已经挖掘过 NPC 至少 3 个**礼物喜好（试错也行）
- **且**玩家**至少 1 次**帮 NPC 完成传话/牵线

#### 2.5.2 触发演出

**玩家在 NPC 房间/店铺/书房** → NPC 主动说："侬坐，阿拉跟侬讲个事……"

**NPC 讲的内容**（LLM 实时生成，但有**素材库**）：
- **项松茂**：讲 1932 一二八殉难的真实经历（"阿拉被东洋人抓的时候……"）
- **方液仙**：讲 1912 用 200 银元创业的苦（"那年头 200 银元够阿拉活 2 年"）
- **郭乐**：讲 1918 在澳大利亚当学徒的日子（"佢在悉尼码头扛过 12 小时货"）
- **巴金**：讲 1931 写《家》时大哥自杀的真相（"大哥走的那天，阿拉在巴黎……"）
- **王婆**：讲丈夫张德顺 1927 年被抓的经过（"4 月 11 日夜里他还帮阿拉缝衣裳"）
- **巡捕阿德**：讲 1932 一二八亲眼看到 3 个中国人被处决的事（"阿拉至今做噩梦"）
- **青帮马仔**：讲 14 岁来上海的第一天（"弄堂里有人抢了阿拉的 5 分钱"）
- **日商买办**：讲 1925 年五卅运动被打的经过（"阿拉左腿瘸了 3 个月"）
- **地下党林先生**：讲 1931 年瑞金突围（"200 里路阿拉走了 9 天"）

**关键**：
- 这些故事是**真实历史/真实经历**——不瞎编
- 这些故事是**NPC 好感度 ≥ 70 才解锁的"奖励"**
- 这些故事**可以分享给其他 NPC**（"项老板跟我讲过 1932 那次……"——但分享有 30% 概率让 NPC 怀疑你）

#### 2.5.3 "朋友聊天"的剧情作用

**每个故事都解锁 1 个新任务**：
- 项松茂讲完 1932 → 玩家解锁"为项松茂立一块纪念碑"任务
- 王婆讲完张德顺 → 玩家解锁"为王婆找丈夫的遗物"任务
- 地下党林先生讲完 1931 突围 → 玩家解锁"为林先生运一批苏区药品"任务

**这些任务都跟抗日/救亡相关**——v7 把"好友聊天"和"抗日"自然衔接。

## Part 4：地下党/抗联 NPC 升级（严谨处理"解放军"问题）

### 4.1 现状问题

用户说"新加一个 NPC，比如这些 NPC 好感度高到一个阈值，就会给你介绍对吧抗日的解放军"。

**严谨性问题**：
- **1936 年没有"解放军"**——中国人民解放军是 1945 年中共七大以后才有的称呼
- 1936 年的中共武装是：
  - **红军**（陕北，1935 年中央红军到达陕北）
  - **东北抗日联军**（1936 年已成立，由杨靖宇/赵尚志/周保中领导）
  - **八路军**（1937.8.22 改编，1936 年还不存在）
  - **新四军**（1937.10 成立，1936 年还不存在）

**解决方案**：
- v5 的 `dixia`（地下党）**保留**——这是上海的中共地下党联络员
- **新增** `kangri`（抗联联络员，1936 年真实存在的组织）
- 玩家**达到地下党高好感度（≥ 60）** → 林先生介绍你认识**抗联联络员**

### 4.2 抗联 NPC 设计

#### 4.2.1 基本信息
- **姓名**：**周保中**（**历史真实人物**，1902-1964，1936 年在东北领导抗联第二路军）
- **游戏设定**：1936 年秘密潜回上海**治病**（史实：周保中 1936 年在战斗中负伤，曾秘密回上海治疗）
- **身份**：抗联第二路军总指挥
- **住所**：法租界某医院（**游戏设定**）
- **玩家怎么见到他**：
  - 跟地下党林先生好感度 ≥ 60
  - 林先生说"阿拉有个老战友在上海养伤，侬帮阿拉送批药过去"
  - 玩家送药到法租界医院 → **第一次见周保中**

#### 4.2.2 周保中的人设

**历史真实**：
- 1902 年生于云南大理
- 1927 年加入中共
- 1931 年九一八事变后赴东北
- 1932 年组建抗联第五军
- 1936 年任抗联第二路军总指挥
- 1945 年配合苏联红军解放东北
- 建国后任云南省副主席

**v7 游戏设定**：
- **年龄**：1936 年 34 岁
- **性格**：刚毅、沉默、有军人的克制
- **身体状况**：右臂中弹未愈（战斗伤）
- **心境**：跟组织失去联系 2 个月（1936 年的"孤岛"）
- **核心需求**：药品 + 武器 + 情报
- **对玩家的态度**：审视——他是军人，对商人天然警惕

#### 4.2.3 周保中能给的 3 件事

1. **抗联物资**（药品/武器）——玩家送到周保中手里，**周保中给玩家"抗联通行证"**（玩家怀疑度大幅降低）
2. **抗联情报**——周保中告诉玩家"1936 年 11 月绥远抗战大捷"（**史实**）——这是**玩家可以预言的事**（不用暴露穿越身份）
3. **最后的使命**——第 91-100 天，周保中让玩家**把一批物资运到十六铺码头**（这批物资要走海路去东北抗联）

#### 4.2.4 周保中的"结局"

**周保中在第 100 天**：
- 周保中已**离沪返东北**（史实：1937 年周保中回东北）
- 玩家在十六铺码头送别周保中
- 周保中说："账房先生，1936 年侬帮了阿拉的忙，**1937 年阿拉会记得**。"

**这是"未来伏笔"**——玩家作为穿越者知道 1937 年会发生什么（淞沪会战/东北沦陷），但**不能说**。周保中这句话**给玩家一个情感锚点**——"未来在抗联那里，我做的事有意义"。

### 4.3 抗联联络员的"加 NPC"机制

#### 4.3.1 触发流程

```
玩家跟地下党林先生好感度 ≥ 60（第 45-60 天）
   ↓
林先生说："阿拉有个老战友，姓周，侬帮阿拉送批药"
   ↓
玩家去十六铺码头黑市买盘尼西林
   ↓
玩家送药到法租界医院
   ↓
玩家第一次见周保中（立绘 + 第一句话）
   ↓
解锁"抗联支线"（最后 30 天）
```

#### 4.3.2 抗联支线任务

| 任务 | 时机 | 内容 |
|---|---|---|
| **送药品** | 第 60 天 | 盘尼西林 ×3（一批）|
| **送情报** | 第 75 天 | 把法租界的日军动向告诉周保中 |
| **送军需** | 第 90 天 | 绷带/汽油/无线电零件（v5 已有军需） |
| **送行** | 第 100 天 | 在十六铺码头送周保中上船 |

#### 4.3.3 抗联支线的好结局

- 周保中关系 ≥ 80 → 玩家获得**"抗联通行证"**（v7 独有物品）
- 抗联通行证 = **怀疑度永久 -20**（NPC 看到抗联通行证，知道你是"自己人"）
- **终章时**玩家可以选择"去东北找周保中"（v5 三选一新增 D 选项）

#### 4.3.4 抗联支线的坏结局

- 周保中被捕（第 80 天） → 玩家**也被捕**（怀疑度 +50） → **触发精神病院结局**

**注**：周保中 1936 年**未被捕**（史实：周保中 1937 年回东北），所以**这是玩家行为的因果后果**——玩家被发现送药给周保中 → 周保中暴露 → 周保中被捕 → 玩家连坐。

## Part 5：最后 10 天"山雨欲来"（严谨时间线 + 戏剧性双赢）

### 5.1 现状问题

**用户的核心要求**："最后 10 天就是抗日的时间"

**史实问题**：1936 年 4 月 9 日（v5 设定第 100 天）**距离 1937.7.7 卢沟桥事变还有 1 年 3 个月**，**距离 1937.8.13 淞沪会战还有 1 年 4 个月**。

**1936 年 4 月没有"真打"**——但**救亡运动高涨**。

**1936.4 的真实事件**：
- 1936.4.4 民国儿童节
- 1936.4.9 清明节后 3 天
- 1936 春 全国抗日救亡运动持续高涨
- 1936.4 绥远抗战余波（1936.11.24 百灵庙大捷后，全国捐款持续到 1937 春）

### 5.2 v7 的"最后 10 天"重新定义

**5 个戏剧元素叠加** = 解决"抗日时间"问题：

#### 5.2.1 元素 1：清明祭祖（第 91-95 天）

**清明节（1936.4.4，农历 1936.3.13）**——玩家作为"账房先生"，**按海派规矩要给曾祖父上坟**。

**剧情**：
- 第 91 天 巴金说"侬要不要去武康路尽头的曾祖墓？清明快到了"
- 第 92 天 玩家去墓地
- 第 93-95 天 玩家发现**曾祖父墓碑上的名字**——**v5 钉一回收**

**为什么是清明**：
- 清明是**海派文化的重要节点**（祭祖/上坟/吃青团）
- 清明是**真实的 1936.4.4**——史实
- 清明**自然衔接"曾祖父线"**——v5 钉一回收

#### 5.2.2 元素 2：山雨欲来（第 95-98 天）

**第 95-98 天的"山雨欲来"**——**不是真打，是紧张气氛**。

**剧情**：
- **第 95 天**：武康路来了**一批北方逃难的学生**（北平"一二·九"学生南下示威后续）——玩家在茶馆听学生讲"华北危急"
- **第 96 天**：王婆收到**老家来信**——山东乡下闹饥荒，**北方逃难的人更多了**
- **第 97 天**：法租界**巡捕增加**（阿德说"听说华北要打仗"）——**戒严气氛**
- **第 98 天**：玩家在五洲大药房**发现 5 包未贴标签的"南洋橡胶"**（其实是军需）——**v5 军需剧情 + 反日元素**

**为什么用"北方学生南下"**：
- 1936.1.13 北平学生南下示威团到上海（**史实**）
- 1936.1.28 一二八事变 4 周年（**史实**）
- **玩家作为穿越者知道 1937 年要打仗**——但**不能说**
- **学生南下是"山雨欲来"的真实信号**

#### 5.2.3 元素 3：梦回 1937（第 95-99 天）

**玩家做"梦"**——**每天晚上 1 个梦**——**梦到 1937 年的事**：

| 梦境日 | 梦里看到的 | 史实 |
|---|---|---|
| **第 95 夜** | 1937.7.7 卢沟桥的炮声 | ✅ 1937.7.7 |
| **第 96 夜** | 1937.8.13 淞沪会战，上海南火车站 | ✅ 1937.8.13 |
| **第 97 夜** | 1937.11 上海沦陷，外滩的难民 | ✅ 1937.11 |
| **第 98 夜** | 武康路被炸成废墟，五洲大药房的木招牌在火里 | ✅ 武康路在战时确实受损 |
| **第 99 夜** | 2026 年武康路咖啡馆，玩家醒来 | ✅ v5 末帧 |

**为什么用"梦"**：
- **梦**是**穿越者最安全的方式**——梦里说什么都不会增加怀疑度（NPC 觉得是"做梦"）
- **梦**是**叙事工具**——LLM 实时生成，给玩家"我知道未来"的感觉
- **梦**是**戏剧性高潮**——**每天 1 个，5 天看完整个抗战**

**但**：玩家**醒来后想说"我梦到 1937 年打仗"**——这会**+30 怀疑度**（王婆尤其快）——玩家**必须憋住不说**，或者**说"我做了个奇怪的梦"**（只 +5）

#### 5.2.4 元素 4：捐款救国（第 95-100 天）

**玩家可以捐款**——**3 个选择**：

| 捐款对象 | 效果 | 史实 |
|---|---|---|
| **绥远抗战基金**（傅作义部队） | 良心 +20，项松茂 +15 | ✅ 1936.11 绥远抗战 |
| **抗联基金**（周保中部） | 良心 +30，周保中 +30，**获得"抗联通行证"** | ✅ 1936 抗联需要捐款 |
| **上海难民基金**（王婆负责） | 良心 +15，王婆 +20 | ✅ 1936 北方逃难人涌入上海 |

**关键**：捐款**不是强迫的**——玩家可以**不捐**（生存 +5，但良心 -10）

#### 5.2.5 元素 5：清明当日的"曾祖墓"（第 100 天上午）

**第 100 天 清明节（农历 1936.3.13，但游戏设定是 4.9 清明节后 3 天）**——

**玩家在曾祖墓前**——**4 核心 NPC + 王婆 + 周保中** + 玩家在场——**8 个人一起祭祖**。

**v6 钉一回收**——账本 + 曾祖父名字——**8 个人同时知道真相**。

### 5.3 第 100 天"山雨欲来"之后的"结局"——v5 已有三选一

**v5 三选一**（魂穿回去/留在 1936/带 NPC 记忆回 2026）**保留**——

- 教学局**强行引导玩家到好结局**（强制项松茂好感 +30 / 强制让玩家买国货）
- 教学局**通过**——再让评委自己玩

## Part 8：v7 关键设计原则（给 LLM 的系统 prompt）

```markdown
【v7 核心原则】

1. **穿越者张力 = 游戏命脉**
   - 玩家每说一句话都可能增加怀疑度
   - 玩家必须在"装本地人"和"用未来信息"之间走钢丝
   - 这是**最大的沉浸感来源**——不是"操作沉浸"，是"角色沉浸"

2. **传话/牵线/挖礼物 = 核心玩法**
   - 玩家要"跑腿"——真正去见每个 NPC
   - 玩家要"送礼"——但要自己去发现 NPC 喜欢什么
   - 玩家要"撮合"——A+B 的关系网联动 = 时代碎片的隐藏获取方式

3. **怀疑度 ≠ 不信任 = 关系网的"另一个轴"**
   - 高怀疑度 + 高好感度 = "NPC 喜欢你但警惕你"（最有戏剧性）
   - 低怀疑度 + 高好感度 = "NPC 信任你"（理想状态，但少有）
   - 高怀疑度 + 低好感度 = "敌人"（坏结局风险）
   - 低怀疑度 + 低好感度 = "陌生人"（冷启动）

4. **时间线严谨 = 历史可信度**
   - 1936.4 没有真打——但有"山雨欲来"+"清明"+"梦回 1937"+"捐款救国"+"周保中"五个元素
   - 不创造"1936 年的抗日战争"——这是**史实错误**
   - 用"梦"+"捐款"+"学生南下"+"周保中"自然带出"抗日"

5. **"挖礼物"无提示 = 真实社交**
   - 玩家要**听其言观其行**——不能给 hint
   - 试错机制**不扣好感**——避免挫败感
   - 王婆的茶馆是**情报中转**——玩家主动问才有线索

6. **抗联 = 严谨的"抗日"**
   - 1936 年没有"解放军"——只有"红军"（陕北）/"抗联"（东北）/"地下党"（上海）
   - 周保中是**史实人物**——抗联第二路军总指挥
   - 1936 年周保中在上海养伤（**史实**）——玩家送药可以见他
```
