# 3 分钟路演脚本

## 0:00-0:30 钩子（V1 视频 + 一句话定位）

**画面**：v1-opener.mp4 播放（黑底白字："1936 年 1 月 1 日，上海武康路。"）

**念**：

> 「1936 年的上海武康路，五洲大药房的账房先生打开店门，发现柜台上多了一本账本——上面写着他曾祖父的名字。这是**AI 经营游戏**《弄堂沉浮录·1936》。100 天后，你必须选择：魂穿回去，还是留在 1936？」

---

## 0:30-1:00 讨价还价三轮博弈（核心 loop）

**画面**：Shop 页面 → 点 131 牙膏的"进货" → Bargain 三轮博弈

**念**：

> 「跟项松茂进货 131 牙膏——他要价 0.08 块，我出 0.05 块，他反价 0.06 块，我再还 0.055 块——这是**三轮博弈**。价格是端侧 5KB 规则引擎算的，但**项松茂说'六分一枝，少一厘勿来谈'——这句话是 AI 现场生成的**，带他的硬气、他的沪语、他对日货的恨。」

---

## 1:00-1:30 AI 演活人（NPC agent 实时情绪）

**画面**：跟项松茂自由对话

**念**：

> 「你跟他说'东洋货便宜'，他立刻翻脸——**AI 实时算情绪影响**。端侧按 personality 调模板，云端 LLM 跑出新的台词。**AI 不再演剧本，AI 演活人。**」

---

## 1:30-2:00 时代碎片 + 终章三选一

**画面**：交易完成弹时代碎片（"131 牙膏的木箱"）→ 跳到 Finale 终章

**念**：

> 「每笔交易 30% 概率掉一件**时代碎片**——真实历史物件。收集到 5 件解锁一段口述史。**第 100 天三选一**——魂穿回去？留在 1936？还是带着所有 NPC 记忆回 2026？我选'传火者'，AI 给我写了 300 字长叙事……」

---

## 2:00-2:30 端云协同实测数据 + IP 延展

**画面**：展示端云协同数据 dashboard + 4 NPC agent schema

**念**：

> 「端侧 5KB 规则引擎跑价格/博弈/状态，**脱敏 < 5ms**；云端 MiniMax-M3 跑 NPC 对话/物价新闻/碎片故事，**8-25 秒响应**。**同样的引擎，明天能装'老北京 1980'、'港片 1990'、'巴黎 1927'**。今天我们用 4 个真实历史人物——项松茂、方液仙、郭乐、巴金——证明：AI 不再演剧本，AI 演活人。」

## 备选：评委提问应对

**Q：端云怎么分工？**

A：端侧 5KB 规则引擎（localStorage + 公式）— 价格计算/讨价还价/状态保存/脱敏
云端 LLM（MiniMax-M3）— NPC 实时对话/每日物价新闻/时代碎片故事/章末预告/终章长叙事
数据流：玩家操作 → 端侧 5ms 脱敏 → 云端 LLM 8-25s → 回流打字机呈现

**Q：离线能玩吗？**

A：能。规则引擎独立跑 3 天可玩，NPC 用性格化 fallback 句（硬气/圆滑/精明/温和四套模板），物价用本地伪随机情绪系数，碎片用预设 15 件 + 兜底口述史。

**Q：商业模式？**

A：试点（3 个月内）跟上海 1933 老场坊合作线下"海派弄堂 AR"体验店
1-2 年 IP 化，把"1935 上海"做成持续更新的内容包
3-5 年平台化，开放 IP 创作工具，创作者 70% / 平台 30% 分成，3 年内积累 100 个 IP 包、1000 万用户

**Q：跟其他 AI 游戏叙事的区别？**

A：其他是 AI 写文案，剧情固定。我们是 AI 当导演，NPC 演活自己。4 个真实历史人物的 memory/emotion/relationship 全部 LLM 实时驱动，玩家的每句话都改变 NPC 下一秒的回应。

1. **0:00-0:30 序章钩子**：开 dev server → 打开 http://localhost:5173 → 首日播放 v1-opener.mp4 → 录 30 秒
