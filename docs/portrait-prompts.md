## 通用前缀（每张必加）

```
1936 年上海滩，民国海派美学，老照片复古色调，竖排中文宋体楷体混合，暖纸色 #F5EFE3 背景，朱砂红 #B03A2E 点缀，墨黑 #1F2A33 主文字，中画幅胶片相机质感，柔和暖光，自然褪色，纸纹颗粒纹理叠加 10%，墨迹晕染效果。

【人物特征（锁定）】
[人物描述]

【主体 + 构图】
半身立绘，平视 5 度角，景深浅（前景人物清晰，后景虚化），暖光从右上方照入。

【元素】
人物主体 + 民国背景元素（药柜/算盘/账本/书架/弄堂窗棂等）

【质感】
中画幅胶片颗粒（Yashica 风格），纸纹叠加，朱砂印章不均匀边缘。

不要水印不要 LOGO 不要现代元素不要 3D 渲染，不要电脑手机打字界面。
```
