### 1.2 可借鉴的关键 UI 模式

**值得学的（5 个）：**

1. **inZOI 头顶气泡（内心独白）**
   - NPC 头顶弹出文字气泡，显示"为什么做这个决定"
   - **我们的应用**：6 因子 portrait 状态条，玩家可点 NPC 头像看"他现在想什么"

2. **inZOI 日记系统（每天 23:00）**
   - NPC 每天写日记，AI 总结 + 反思 + 规划次日
   - **我们的应用**：finale 终章信 + 每天 5 天的 storylineEngine 自动推进（已实现 21 次/100天）

3. **昭阳传 "朝闻简帖"（每日人物小传）**
   - 每天登基朝议后更新一则人物小传
   - **我们的应用**：每天 4 NPC 长条卡 + 老日历翻页过渡（套图 9）

4. **WFS 跨星际延迟（叙事化等待）**
   - AI 响应时间被包装为"信号传输"
   - **我们的应用**：loading 屏幕"项松茂正在斟酌措辞..."（套图 6）

5. **黑色洛城 三层审讯（施压/克制/共情）**
   - 不设标准答案，以"回应质量层级"衡量
   - **我们的应用**：branching A/B 选择（已实现 6 真分支）

**绝对不要的（4 个）：**

1. ❌ 3D 实时渲染（inZOI）—— 13 天时间撑不住
2. ❌ 视频通话界面（WFS）—— 我们是文字型, 视频成本太高
3. ❌ 政令系统（昭阳传）—— 我们是 1V1 NPC 对话, 没有治国
4. ❌ 通用模板 UI —— 跟《上海故事》/《黑色洛城 1936》重复

### 3.2 字体系统

- **标题**：方正清刻本悦宋（粗细对比 + 笔锋）
- **正文**：思源宋体 SC（古典印刷感）
- **沪语**：楷体（手写温度）
- **英文字体**：Caslon Antique（1920-1940 时期流行）
- **数字**：老式打字机字体（Courier 改良）

### 3.3 装饰元素库（1936 海派符号集）

| 元素 | 描述 | 用途 |
|------|------|------|
| 朱砂印章 | 圆形篆刻（直径 40-80px），不均匀边缘 | 标题装饰 / 重要按钮 |
| 老式信纸 | 横纹纸 + 红色竖线 + 折痕 | 背景底纹 |
| 烟纸店招贴 | 黄底 + 朱红大字 + 老电影海报风格 | 邀请页 / 通知 |
| 老电影海报 | 粗黑线框 + 侧脸人物 + 颜色块 | 终章信 / 结局页 |
| 老日历 | 公历 + 农历 + 二十四节气 | 进度显示 |
| 民国月份牌 | 旗袍美女 + 月份 + 旧商标 | 季度切换 |
| 五洲大药房商标 | 圆边 + 中英对照 "五洲大药房 / WUZHOU PHARMACY" | 玩家身份标识 |
| 哈德门 / 老刀牌 | 真实民国香烟品牌 | 道具 / 时代感 |

### 3.4 纹理叠加

- **纸纹颗粒**：10% 透明度叠加（避免锐利感）
- **墨迹晕染**：避免矢量锐边，统一加 2px 羽化
- **朱砂不均匀**：手工盖章感（不要完美圆形）
- **边缘做旧**：暖纸色阴影 + 磨损痕迹

### 3.5 排版原则

- **不规则对齐**：手写感 + 不齐头（模仿民国印刷）
- **粗细对比**：标题 64-96px / 正文 14-18px / 注脚 10-12px
- **中文为主**：英文只作辅助（"WUZHOU PHARMACY · 1936"）
- **沪语混排**：沪语用楷体 + 朱砂红 + 引号包裹（"侬好"）

## 六、6 大关键交互模式

1. **点 NPC 头像 → Dialogue**
   - 9 NPC 长条卡（4 真实 + 5 邻里），圆形头像 + 名字 + 角色 + 生卒年
   - 真实人物有金色边框，邻里为普通边框

2. **打字 → 30-80 字限制**
   - 超过不让发（行业痛点：WFS 等待长 + 不可控）
   - 输入框带"剩余 N 字"提示

3. **A/B 选择 → branching**
   - 对话滚到底 → 出现 A/B 选择按钮（朱砂红 + 墨黑）
   - 已实现 6 真分支（qingbang/rishang/dixia/conscience/survival/neutral）

4. **每天 4 次对话**
   - 顶栏显示"对话 N/4"
   - 用完后弹"打烊"提示

5. **portrait 6 因子可视化**
   - 顶部横条：trust/respect/patience/tension/intimacy/energy
   - 6 条色块，hover 显示数值
   - 学习 inZOI 头顶气泡思路

6. **失败提示（老式告示）**
   - 破产："本铺即日起关闭"
   - 青帮打："沪上风云 江湖难测"
   - 被捕："法租界巡捕房 案号 1936-0XX"
   - 孤立："沪上无人识君"

## 七、工业级 Prompt 模板（豆包专用）

> **核心**：豆包对中文 prompt + 详细描述 + 强风格锚定最有效

### 7.1 通用结构

```
【风格锚定前缀 - 必填】
1936 年上海滩老照片风格，民国海派美学，
竖排中文宋体 + 民国月份牌 + 朱砂红印章 + 暖纸色颗粒纹理，
中画幅胶片相机质感，柔和暖光，自然褪色，
不要水印，不要现代元素，不要 3D 渲染

【主体描述 - 必填】
{具体场景 / 人物 / 物体}

【构图 + 光线 - 必填】
{视角} + {景深} + {光线方向} + {色调倾向}

【元素清单 - 必填】
{关键元素 1} + {关键元素 2} + ...

【质感 / 纹理 - 必填】
{纸纹 / 墨迹 / 朱砂 / 皮革 / ...}

【负面词 - 必填】
不要水印，不要 LOGO，不要现代标志
```

### 7.2 关键参数

- **比例**：在豆包 UI 选（不要写在 prompt 里）
  - 套图 1/4/5：16:9 横向
  - 套图 2/3/6：3:4 纵向
  - 套图 7/8/9/10：1:1 方形
- **参考强度**：0.7-0.8（豆包"图生图"模式）
- **风格词密度**：60% 风格锚定 + 40% 主体描述
- **元素数量**：5-8 个（不要太多，豆包会乱）
- **文字处理**：中文写"宋体楷体混合"，避免豆包加奇怪字体

### 7.3 工业级 7 大原则

1. **风格锁定**：每张图首句重复 1936/民国/海派/朱砂 关键词
2. **明确主体**：先说主体是什么，再说环境
3. **强构图描述**：俯视/平视/特写/全景 + 前景/中景/远景
4. **光线锚定**：暖光从左/右 + 阴影方向 + 软硬程度
5. **色板精准**：直接用 hex 或"暖纸色 #F5EFE3 + 朱砂 #B03A2E"
6. **质感具体**：胶片颗粒 + 纸纹 + 墨迹 + 朱砂不均匀
7. **负面词必填**：每次都写"不要水印/LOGO/现代元素/3D 渲染"

### 7.4 10 张套图通用前缀（统一锁定）

```
1936 年上海滩，民国海派美学，老照片复古色调，
竖排中文宋体楷体混合，暖纸色 #F5EFE3 背景，
朱砂红 #B03A2E 点缀，墨黑 #1F2A33 主文字，
中画幅胶片相机质感，柔和暖光，自然褪色，
纸纹颗粒纹理叠加 10%，墨迹晕染效果，
中英对照老式印刷，朱砂印章不均匀边缘，
不要水印不要 LOGO 不要现代元素不要 3D 渲染，
不要 2020 年后的电子产品
```
